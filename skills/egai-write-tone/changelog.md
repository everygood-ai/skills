# Changelog

- `3.0.1` — Fixed a compliance gap found in live use: a calling skill that invoked this skill "in `terse` mode" but only read `references/terse.md`, not this skill's `SKILL.md` workflow, skipped the dedupe-before-drafting step and produced flowing, restated prose despite the mode's rules. Added a "Before you draft" section to each of `prose.md`, `terse.md`, and `compact.md` restating the dedupe step directly in the reference file, so it survives a partial invocation. Sharpened `prose` and `terse` mode's self-check sections to explicitly name flowing connective prose and mid-document restatement as failure modes to catch, since a linter cannot detect either.
- `3.0.0` — Replaced the ASD-STE100 grounding with a redundancy-first approach. Testing showed ASD-STE100's grammar rules made `prose` and `terse` output LONGER than an unstyled baseline on every source tried, because sentence-splitting and word-substitution rules were built for parseability, not compression. The workflow now dedupes ideas before writing, in every mode, and each mode renders that reduced idea set instead of the original wording. `terse` mode no longer targets ASD-STE100 compliance: renamed `references/asd-ste100.md` to `references/terse.md`, dropped the approved-dictionary/word-cap framing, and rewrote it around one-idea-per-line plus heading-grouped structure. `prose` mode gained a hard sentence-simplicity rule (one idea per sentence, roughly 10-20 words, split anything needing a semicolon or em-dash aside) and explicit permission to use headings/lists/tables instead of flattening list-shaped content into paragraphs. Removed the ASD-STE100-specific Vale rules (`NoContractions`, `ComplexVerbForms`, `ParagraphSentenceCount`); downgraded `NoSemicolons` from error to warning since it is now this skill's own preference, not an external standard; added `EGAIProse/StackedClauseHint` to flag semicolons and em-dashes in prose mode.
- `2.0.0` — Renamed the three tone modes: `low` to `prose`, `medium` to `terse`, `high` to `compact`. Renamed the matching reference files, Vale configs, and Vale style folders (`EGAILow`/`EGAIMedium`/`EGAIHigh` to `EGAIProse`/`EGAITerse`/`EGAICompact`). A caller passing the old mode names now fails validation.
- `1.1.0` — Added `scripts/lint.sh`, a bundled Vale style package (structural rules per mode: sentence/paragraph length, contractions, semicolons, Latin abbreviations, complex verbs, filler words, symbol reminders), and a `compatibility` note for the vale CLI dependency.
- `1.0.0` — Created the initial skill with low, medium, and high tone modes and a bundled ASD-STE100 baseline.
